# Seguridad

No publiques contraseñas, tokens, claves privadas ni datos personales en issues o pull requests.

Para reportar una vulnerabilidad, utiliza **Report a vulnerability** en la pestaña Security del repositorio si está disponible. Si no lo está, contacta con el mantenedor de manera privada antes de divulgar detalles técnicos que permitan explotar el problema.

La extensión solicita permisos amplios de acceso a páginas HTTP/HTTPS y el programa acepta conexiones de una extensión local. Revisa `INFORME_SEGURIDAD.md` y `web_extension/manifest.json` antes de instalar.

Las pruebas estáticas no garantizan ausencia de vulnerabilidades. Las versiones publicadas deben probarse en Windows y Linux y sus dependencias deben auditarse regularmente.
