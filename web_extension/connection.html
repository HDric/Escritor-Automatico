Conexión con Escritor Automático

Esta pestaña mantiene el canal local entre la aplicación y la extensión. Déjala abierta mientras utilices la escritura web.

Todavía no se ha iniciado la conexión. Pulsa «Conectar» para permitir que el navegador establezca el canal local.

La conexión utiliza 127.0.0.1:8765 y el código de vinculación guardado en la extensión. Si el navegador muestra un permiso para acceder a aplicaciones o dispositivos locales, permite la conexión para que la aplicación pueda comunicarse con este equipo.
