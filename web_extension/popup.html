Escritor automático

Compatible con Brave, Chrome y Edge. Conecta la extensión con Escritor automático y actualiza las pestañas detectadas.

Abre Escritor Automático, entra en modo web y copia el código de vinculación.

El código queda guardado en el almacenamiento local de esta extensión. Los permisos de páginas se solicitan solo después de pulsar el botón y aceptar el aviso del navegador.
